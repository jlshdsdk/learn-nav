# 我的学习导航

纯静态、零依赖的个人学习网站索引导航页。整个网站只有一个 `index.html` 文件（<10KB），所有 CSS/JS 全部内嵌，双击本地即可运行，也可通过 GitHub Pages 跨设备访问。

## 在线访问

<https://jlshdsdk.github.io/learn-nav/>

## 功能

- 分类卡片导航，点击卡片新标签页打开
- 顶部搜索框实时筛选（匹配名称 / 简介 / 分类）
- 星标收藏常用网站（localStorage 本机记忆，置顶显示）
- 响应式：电脑 3 列 / 平板 2 列 / 手机 1 列

## 如何增删网站

用文本编辑器打开 `index.html`，搜索「网站数据区」，按注释复制/删除/修改 `SITES` 数组里的一行对象即可，无需任何前端知识。详细教程见 `index.html` 文件末尾的注释。
